# REDPLAY GAMES — Android store prototype

مشروع أندرويد باللغة العربية بتصميم أسود/أحمر باستخدام Kotlin وJetpack Compose.

## الموجود في هذه النسخة
- شاشة رئيسية بواجهة REDPLAY وبانر للألعاب المميزة.
- مكتبة ابتدائية تضم 20 لعبة مع التصنيفات والأوصاف.
- بحث داخل الألعاب وتصنيف حسب النوع.
- صفحات تفاصيل لكل لعبة.
- روابط تفتح صفحة البحث عن اللعبة في Google Play بدلاً من روابط APK غير موثوقة.
- مفضلة محفوظة محلياً على الجهاز.
- شريط تنقل: الرئيسية، الألعاب، المفضلة، حسابي.
- لوحة إدارة محلية لإضافة الألعاب وتعديلها وحذفها.
- حفظ بيانات الألعاب والمفضلة على الجهاز باستخدام SharedPreferences.
- GitHub Actions لبناء Debug APK.

## حدود النسخة الحالية
- هذه نسخة متجر محلية أولية قابلة للتطوير، وليست خدمة متجر متصلة بخادم.
- لوحة الإدارة ليست محمية بحساب مدير؛ لا تنشرها كلوحة إدارة عامة أو تضع بيانات حساسة فيها.
- لا توجد مزامنة بين أجهزة المستخدمين، ولا نظام حسابات أو إشعارات Push.
- بطاقات الألعاب تستخدم معالجة رسومية نصية مؤقتة؛ لم تُضمّن أغلفة الألعاب الرسمية.
- الروابط الافتراضية تفتح نتائج بحث Google Play، وليست روابط APK مباشرة.
- حالة الاتصال والحجم معلومات إرشادية وليست ضماناً لكل إصدار أو منطقة.
- لم يتم بناء APK أو اختباره على جهاز فعلي في هذه البيئة.

## بناء APK عبر GitHub من الهاتف
1. فك ضغط ملف ZIP.
2. أنشئ مستودعاً جديداً باسم `RedPlayGames` على GitHub.
3. ارفع محتويات مجلد `RedPlayGames` إلى جذر المستودع، مع مجلد `.github` المخفي.
4. افتح تبويب Actions.
5. شغّل `Build RedPlay Games APK` بواسطة Run workflow أو ادفع commit جديداً إلى فرع `main`.
6. بعد نجاح البناء، افتح الـ workflow run ثم نزّل Artifact باسم `RedPlay-Games-debug-APK`.
7. فك ضغط الـ Artifact وثبّت `app-debug.apk` على جهاز أندرويد.

## المتطلبات
- JDK 17
- Gradle 8.9
- Android Gradle Plugin 8.7.3
- Kotlin 2.0.21
- Android SDK 35

## تطوير النسخة الإنتاجية
لتحويلها إلى متجر كامل متعدد المستخدمين، يلزم إعداد Backend وقاعدة بيانات وتسجيل دخول بصلاحيات، تخزين صور، لوحة إدارة آمنة، ومراجعة حقوق توزيع كل ملف. لا ترفع ملفات APK إلا إذا كنت تملك حق توزيعها.
