# RedPlay Games — Android starter v2

مشروع أندرويد عربي لمكتبة ألعاب بتصميم أسود وأحمر، باستخدام Kotlin وJetpack Compose.

## الموجود
- واجهة رئيسية عربية وشعار REDPLAY نصي أحمر.
- بحث وتصنيفات وبطاقات ألعاب وصفحات تفاصيل.
- مفضلة داخل الجلسة.
- لوحة إدارة محلية لإضافة لعبة ورابط تنزيل HTTP/HTTPS.
- حفظ قائمة الألعاب المضافة محلياً على الجهاز.
- GitHub Actions workflow لبناء APK تلقائياً.

## بناء APK من الهاتف باستخدام GitHub
1. فك ضغط ملف المشروع.
2. أنشئ مستودعاً جديداً على GitHub باسم `RedPlayGames`.
3. ارفع محتويات مجلد المشروع إلى جذر المستودع (لا ترفع ملف ZIP وحده).
4. تأكد من رفع المجلد المخفي `.github/workflows/build-apk.yml`. إذا لم يظهر في مدير الملفات، أنشئ الملف يدوياً في GitHub بالمسار نفسه والصق محتوى ملف workflow الموجود في الحزمة.
5. افتح تبويب Actions في المستودع.
6. افتح `Build RedPlay Games APK` ثم اضغط `Run workflow` إذا لم يبدأ البناء تلقائياً.
7. انتظر حتى تنتهي المهمة بعلامة خضراء.
8. افتح تشغيل المهمة الناجح، وانزل إلى Artifacts، ثم نزّل `RedPlay-Games-debug-APK`.
9. فك ضغط ملف الـ Artifact؛ ستجد `app-debug.apk`. افتحه للتثبيت، واسمح بالتثبيت من Chrome أو تطبيق الملفات عند الطلب.

## متطلبات البناء
- JDK 17
- Gradle 8.9
- Android Gradle Plugin 8.7.3
- Android SDK 35

## ملاحظات مهمة
- هذه نسخة Debug أولية وليست إصداراً منشوراً أو موقّعاً للنشر على المتجر.
- لوحة الإدارة محلية وغير محمية بكلمة مرور، ولا تدعم مزامنة بين الأجهزة.
- روابط التحميل يجب أن تكون مباشرة وموثوقة وتملك حق توزيع الملفات المرتبطة بها.
- زر التحميل يفتح رابط HTTP/HTTPS في المتصفح؛ لا يقوم بتنزيل الملف داخل التطبيق.
- بيانات الألعاب الحالية تجريبية، وصور الألعاب الحقيقية وأيقونة التطبيق المخصصة لم تُضف بعد.
- لم يتم التحقق من البناء على جهاز فعلي في هذه البيئة.
